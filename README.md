# 💱 Currency Converter

A sleek, responsive, and real-time **Currency Converter** built with JavaScript. This tool fetches live exchange rates to provide accurate conversions between global currencies .

---

## 🚀 Features

* **Real-Time Rates:** Integration with external APIs for up-to-date conversion data.
* **Dynamic Flags:** UI automatically updates country flags based on selection.
* **Mobile Responsive:** A centered card design that works on all screen sizes.
* **Clean UI:** Simple, distraction-free interface for quick calculations.

---

| Technology | Purpose |
| :--- | :--- |
| **HTML5** | Semantic structure |
| **CSS3** | Custom styling & Layout |
| **JavaScript** | Logic & API Fetching |
| **FlagsAPI** | Real-time flag rendering |
